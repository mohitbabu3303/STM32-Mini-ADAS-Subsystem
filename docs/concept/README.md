# Original concept (not implemented)

These two files are the **initial project proposal** written before development:

- `original-project-proposal.pdf`
- `original-concept-block-diagram.png`

They describe a larger target system (STM32F4, ultrasonic/IR/camera sensors,
TinyML inference, buzzer/OLED, watchdog task) that has **not** been built.
They are kept only to document where the project started and where it may go.

The firmware that actually exists is described in the main [README](../../README.md)
and in [`docs/architecture.png`](../architecture.png).
